Not a screenshot. A living interface.

Rayo runs as a transparent, click-through layer on your desktop. It reads real data and reacts to it.

Live system telemetry

CPU, memory, disk, battery with charge ETA, network throughput, weather, and a real-time fan speedometer. Read straight from the kernel, no daemons.

Interactive hub

Click the reactor for a radial menu. Double-click for power controls. It is your desktop's command center.

Featherweight

Animation pauses when a window covers it, so it idles near 0% CPU. Your fan stays quiet.

Themeable

One JSON file per theme. Recolours the entire HUD.

Any resolution

Scales to fit any screen. Multi-monitor aware.

Yours to fork

MIT. Plain HTML, CSS, and Python. No build step.

Get started

Running in under a minute.

Works on GNOME, KDE, and most Linux desktops. Needs Python 3 and WebKitGTK, which ship with most distros.

one line
# clone and switch on the overlay
git clone https://github.com/GbadeboMotunrayo/Rayo.git
cd Rayo && ./start.sh
  1. 1
    Clone the repo

    Grab it from GitHub. It is a few hundred KB, no heavy assets.

  2. 2
    Run ./start.sh

    Sets a clean backdrop and mounts the transparent overlay on your desktop.

  3. 3
    Click the reactor

    Open the hub, cycle themes, or wire it to autostart so it is there every login.
